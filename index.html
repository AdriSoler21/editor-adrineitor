Conexión con GitHub

El editor lee y guarda los planos directamente en tu repositorio. Necesita un token de GitHub con permiso solo para este repositorio: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token → Repository access: Only select repositories (este) → Permissions: Contents: Read and write y Actions: Read-only. El token se guarda solo en este navegador.
