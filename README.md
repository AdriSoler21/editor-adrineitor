# Editor · Mira por dónde pisas

Editor del vídeo largo del canal, en el navegador: <https://adrisoler21.github.io/editor-adrineitor/>

Este repositorio solo tiene **la página del editor**: no tiene guiones, vídeos, voces ni claves. Los datos viven en el
repositorio privado `agente-creador-contenido`; el editor los lee y los guarda allí con el token de GitHub que cada
persona pega una vez en «Conexión» (se queda solo en su navegador).

- `index.html`: el editor. El original está en `agente-creador-contenido/editor/editor.html`; esta es una copia.
- `manifest.webmanifest`, `sw.js`, `icono*`: para poder instalarlo como aplicación (Chrome o Edge: menú → «Instalar»).

_Publicado con GitHub Pages desde la rama `main`._
